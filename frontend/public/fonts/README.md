These fonts are served locally so the wall frame does not need Internet access.

Source: https://github.com/google/fonts (downloaded 2026-11-05).

- `ofl/archivo/Archivo[wdth,wght].ttf` → `Archivo-variable.ttf`
- `ofl/instrumentserif/InstrumentSerif-Regular.ttf`
- `ofl/instrumentserif/InstrumentSerif-Italic.ttf`

Both families use the SIL Open Font License; their original licences are included
as `Archivo-OFL.txt` and `InstrumentSerif-OFL.txt`. Preserve them when updating.
